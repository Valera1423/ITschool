# Условия и ограничения

## Файлы

| Параметр | Значение |
|---|---|
| Максимальный размер | 20 МБ |
| Разрешённые расширения | png, jpg, jpeg, pdf, zip, gz, gzip, rar, doc, docx, xls, xlsx |
| Хранилище | MinIO (S3-совместимое) |
| Максимум в одном комментарии | 20 вложений |

## Запросы к API

| Параметр | Значение |
|---|---|
| Размер тела запроса (JSON) | 5 МБ |
| Размер multipart (файлы) | 20 МБ |
| Тайм-аут | 60 с (клиент — 30 с) |
| Rate-limit (глобальный) | 200 запросов / минута на пользователя |
| Rate-limit (strict) | 20 / минута (например, поиск, экспорт) |
| Rate-limit (отчёты) | 30 / минута |

## Данные

| Сущность | Ограничение |
|---|---|
| Soft-delete корзина | 30 дней, затем физическое удаление (cron 3:00) |
| Audit log retention | 90 дней |
| Integration sync logs | 90 дней |
| Notifications | 30 дней |
| Idempotency keys | 24 часа |
| Excel-export sessions | 7 дней |

## Пагинация

| Параметр | Значение |
|---|---|
| По умолчанию pageSize | 25 |
| Максимум pageSize | 100 |
| Максимум bulk-операции | 5000 ids за раз |
| Размер чанка bulk | 200 (на клиенте) |

## WebSocket

| Параметр | Значение |
|---|---|
| Max payload | 64 КБ |
| Ping interval | 30 сек |
| Endpoint | `/ws?token=<jwt>` |
| Переподключение | exponential backoff, до 60 с |

## Аналитика

| Параметр | Значение |
|---|---|
| TTL кэша ABC/XYZ | 5 мин |
| TTL кэша RFM/LTV/когорты | 10 мин |
| Максимум когорт | 36 месяцев |
| Экспорт отчётов | 10 000 строк (для CSV) |

## Безопасность

| Параметр | Значение |
|---|---|
| Длина PII_KEY | ≥ 32 символа |
| Длина OAUTH_STATE_SECRET | ≥ 32 символа (или fallback на KEYCLOAK_CLIENT_SECRET) |
| OAuth state TTL | 10 минут |
| Session idle timeout | 30 минут |
| Пароль (Keycloak) | 12+ символов, цифры, регистры, спецсимвол |
| Парольная история | 5 последних |

## Интеграции

| Параметр | Значение |
|---|---|
| Тайм-аут запроса | 30 секунд |
| Retry | 3 попытки, exponential backoff |
| Максимум записей за sync | не ограничено (батчи по 100) |

## Инфраструктура

| Параметр | Значение |
|---|---|
| Целевая нагрузка | 50 параллельных пользователей |
| Параллельные отчёты | 10 |
| Время отклика UI | < 1 с (p95) |
| Минимум RAM (prod) | 8 ГБ |
| Минимум CPU (prod) | 4 ядра |

## Что НЕ поддерживается

- Multi-tenancy (один инстанс = одна ИТ-Школа)
- Offline-режим с синхронизацией (только кэш для чтения)
- Интеграция с 1С/SAP по умолчанию выключена (требует настройки)
- Импорт более 5000 строк за раз (использовать Excel-по-партиям)
- Хранение PII в plaintext (всегда шифруется через PII_KEY)
