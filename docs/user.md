# Руководство пользователя

**Для менеджеров ИТ Школы Ростелеком (роль НАМ) и руководителей.**

> Полная версия с картинками доступна внутри CRM:
> **База знаний → Руководство пользователя**.

## Кто вы в системе

### Менеджер (НАМ)

- Видите **только свои** вузы (где вы ответственный)
- Создаёте и редактируете карточки
- Ведёте взаимодействия
- Работаете с задачами и календарём
- Оставляете комментарии
- Смотрите аналитику и отчёты

### Руководитель

- Всё, что менеджер, **плюс:**
- Видите **все** вузы
- Передаёте вузы между менеджерами
- Массово меняете статусы
- Сравниваете периоды

## Вход

1. Откройте https://crm.example.ru
2. Нажмите **«Войти через SSO»**
3. Введите корпоративные учётные данные
4. При первом входе настройте 2FA (если требуется)

## Работа с вузами

### Список

- Фильтры: статус, направление, продукт, менеджер
- Поиск по названию, городу, контактам
- Массовые операции: выделить → панель действий

### Карточка

| Вкладка | Что |
|---|---|
| **Обзор** | Основные поля |
| **Контакты** | Ответственные от вуза |
| **Workflow** | Прогресс по шагам |
| **Взаимодействия** | Все касания |
| **Задачи** | Открытые |
| **Документы** | Файлы |
| **Договоры** | Согласования |
| **Комментарии** | Обсуждения |
| **Timeline** | Хронология |

### Создать вуз

1. **Вузы → Добавить**
2. Заполните обязательные поля:
   - Название
   - Город
   - Направление
   - Продукт
   - Статус
3. Сохранить

Если вы НАМ — вуз автоматически создастся на вас.

## Взаимодействия

- **Звонок, Встреча, Письмо, Документ**
- Создать: **Взаимодействия → +** или из карточки вуза
- Встречи синхронизируются с Google Calendar

## Задачи

- Создать: **Задачи → +** или `n t`
- Канбан-доска: перетаскивание между статусами
- Передать коллеге: **⋯ → Передать**

## Аналитика

### ABC/XYZ

- **A** — 80% выручки (VIP)
- **B** — 15%
- **C** — 5%
- **X, Y, Z** — стабильность касаний

### RFM

- **R** — Recency (когда последнее касание)
- **F** — Frequency (как часто)
- **M** — Monetary (сколько выручки)

Сегменты: Чемпионы, Лояльные, В зоне риска, Потерянные.

### LTV

- Lifetime value
- Средний в месяц
- Прогноз на 12 мес

## Настройки

### Профиль

- ФИО, телефон, цвет аватара
- **Email не меняется** (из Keycloak)

### 2FA (для admin/manager)

**Настройки → Безопасность → 2FA → Настроить**

Установите Google Authenticator / Яндекс.Ключ.

### Google Calendar

**Настройки → Интеграции → Google → Подключить**

### Push-уведомления

Разрешить в браузере, нажать **«Тестовый push»**.

### Тёмная тема

Переключатель в правом верхнем углу.

## FAQ

**Забыл пароль** → К администратору.

**Не вижу чужих вузов** → Роль НАМ видит только свои.

**Пустой список** → Возможно, вам ещё не назначены вузы.

**Файл не загружается** → Проверьте формат (png, jpeg, pdf, zip, gzip, rar, doc, docx, xls, xlsx) и размер (≤20 МБ). Возможно, антивирус нашёл угрозу.

**Сессия истекла** → Idle-таймаут 30 минут. Войдите заново.

**Ошибка CRM-XXX-YYY** → [Полный список](../limitations.md).
