# Обработка персональных данных

Документ описывает, какие ПД обрабатываются в CRM ИТ Школы
Ростелеком, как они защищены и как реализуются права субъектов
по **152-ФЗ**.

## 1. Правовые основания

- **ФЗ-152** от 27.07.2006 «О персональных данных».
- **ПП №1119** от 01.11.2012 — уровни защищённости.
- **Приказ ФСТЭК №117** — требования к защите информации.
- Согласие субъекта — основное основание для обработки
  контактных данных представителей вузов.

## 2. Перечень обрабатываемых ПД

| Категория | Состав | Правовое основание |
|---|---|---|
| ПД сотрудников ИТ Школы | ФИО, email, телефон, роль, IP | Трудовой договор |
| ПД представителей вузов | ФИО, email, телефон, мессенджеры | Согласие |
| ПД студентов (из LMS) | ФИО, email, id-в-LMS | Согласие, договор с вузом |

**Специальные категории ПД** (расовые, политические, религиозные,
биометрические, о здоровье) — **не обрабатываются**.

## 3. Цели обработки

- Ведение карточек вузов и управление взаимодействием.
- Формирование отчётов для руководства.
- Интеграция с LMS и сайтом для получения актуальных данных.
- Отправка уведомлений (email, push, мессенджеры).

## 4. Место хранения

- **PostgreSQL** — основная БД, шифрование ПД-полей через `PiiService` (AES-256-GCM).
- **MinIO** — файлы (договоры, лицензии), доступ по signed URL.
- **Redis** — кэш, не содержит ПД в открытом виде.
- **Резервные копии** — `./backups/*.sql.gz`, шифрование тома на уровне ОС.

## 5. Сроки хранения

| Категория | Срок | Основание |
|---|---|---|
| Карточки вузов | Бессрочно, пока действует партнёрство | Бизнес-необходимость |
| Контактные лица | Пока действует партнёрство + 1 год | 152-ФЗ |
| Audit-логи | 90 дней | Внутренний регламент |
| Журнал доступа к ПД | 1 год | ФСТЭК №117 |
| Согласия | Пока не отозваны + 3 года | 152-ФЗ |
| Корзина (soft-delete) | 30 дней | Внутренний регламент |

## 6. Реализация прав субъектов

### 6.1 Право на доступ (ст. 14 152-ФЗ)

Раздел **Безопасность → Персональные данные** → «Экспорт JSON».
По email-у возвращаются все ПД, связанные с субъектом:
карточки вузов, контакты, взаимодействия, комментарии.

Реализация: `POST /security/pd/export { email }`.

### 6.2 Право на забвение (ст. 21 152-ФЗ)

Раздел **Безопасность → Персональные данные** → «Удалить ПД».
Анонимизация (не физическое удаление, чтобы сохранить статистику).

Реализация: `POST /security/pd/forget { email }` — обнуляет
`email`, `phone`, `telegram`, `whatsapp` в `university_contacts`.

### 6.3 Право на отзыв согласия (ст. 9 152-ФЗ)

Раздел **Безопасность → Согласия** → кнопка «Отозвать» на активном
согласии.

Реализация: `PATCH /security/consents/:id { granted: false }`.

## 7. Меры защиты

См. [SECURITY.md](SECURITY.md), раздел 5.

Кратко:
- шифрование ПД на уровне приложения;
- журнал доступа (`pii_access_log`);
- 2FA для привилегированных пользователей;
- антивирус для файлов;
- разграничение доступа (RBAC + scopes).

## 8. Уведомление об утечке

При обнаружении утечки ПД:

1. Локализовать инцидент.
2. Оценить масштаб: `SELECT count(*) FROM pii_access_log WHERE created_at > ...`.
3. Уведомить Роскомнадзор в течение **24 часов**.
4. Уведомить субъектов ПД — в течение **72 часов**.
5. Зафиксировать инцидент в `security_events`.

## 9. Ответственные

- **Оператор ПД**: ООО «РТК ИТ Школа».
- **Ответственный за организацию обработки**: admin@rt.ru.
- **DPO (Data Protection Officer)**: по запросу.
